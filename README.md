## Project Name
CI/CD Final Project

## Project Description
This project demonstrates Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions, Tekton and OpenShift.

## Technologies Used
- GitHub
- GitHub Actions
- Python
- Flake8
- Nose
- Tekton
- OpenShift
- Buildah

## Project Objectives
1. Automate code quality checks using Flake8.
2. Run unit tests using Nose.
3. Build container images using Buildah.
4. Deploy the application using OpenShift Pipelines.
